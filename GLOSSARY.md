# Dashboard Icons

A curated collection of service and application icons, grown through community contributions that maintainers review and publish.

## Contributions

**Icon**:
One product in the collection under one slug, with its own aliases, categories and Variants. Different versions of the same product, such as Sonarr and Sonarr 4K, are one Icon.
_Avoid_: Entry, logo

**Submission**:
One contributor's proposal for one Icon, reviewed and decided on its own. A contributor can send several Submissions at once.
_Avoid_: Request, batch

**Update proposal**:
A Submission that edits an Icon that already exists, for example by adding a Variant.
_Avoid_: Edit request, modification

**Rejection**:
A reviewer's decision not to accept a Submission as it stands, with a reason. It is never final: the contributor can fix and resubmit the same Submission.
_Avoid_: Changes requested, decline

## Variants

**Variant**:
One file of an Icon. Every Icon has exactly one Base; the others are well-known Variants or Custom variants.
_Avoid_: Version, flavour

**Base**:
The required, default Variant of an Icon, usually in brand colours.
_Avoid_: Main icon, default icon

**Light variant**:
A light-coloured Variant meant for dark backgrounds.
_Avoid_: White variant

**Dark variant**:
A dark-coloured Variant meant for light backgrounds.
_Avoid_: Black variant

**Wordmark**:
A Variant that shows the brand name as text, in colour, light or dark.
_Avoid_: Text logo, logotype

**Custom variant**:
A Variant with a contributor-chosen name beyond the well-known ones, such as `4k` or `animated`.
_Avoid_: Extra variant, additional icon

**Asset**:
The uploaded file behind a Variant.
_Avoid_: Attachment
