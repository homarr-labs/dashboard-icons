# Share-image assets

Hermes Agent is fetched at generation time from [LobeHub](https://cdn.jsdelivr.net/npm/@lobehub/icons-static-png@latest/dark/hermesagent.png). It is not bundled locally. Other icons come from the repository's `png` directory.

`Inter-Regular.ttf` and `Inter-Bold.ttf` are the website's Inter typeface, downloaded from Google Fonts. Licensed under the SIL Open Font License; see `Inter-OFL.txt`.
