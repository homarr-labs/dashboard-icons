# Native Icon display names

`formatIconName(slug, { capitalize: true, aliases })` is the single native display-name path. Pick the first alias containing an uppercase character whose value matches the slug after removing whitespace, hyphens and periods and comparing case-insensitively. Preserve its casing, punctuation and spacing, trimming surrounding whitespace. Otherwise, split the slug on hyphens and uppercase the first character of each word. Nonmatching search aliases, such as `Firewall` for `pfsense`, never become display names. Lowercase self-aliases do not override the title-case fallback. Periods allow verified names such as `MLB.TV` to match `mlb-tv`.

The native page title, descriptions, Open Graph and Twitter metadata, JSON-LD names, breadcrumbs, H1, image alt text, customizer and share image all use this path. Do not apply CSS `capitalize` to the H1: it would change `pfSense` to `PfSense`. External Icons retain the name supplied by their source.

`metadata.json` supplies the aliases. Put a preferred brand-cased matching alias first when several match. This is additive and needs no new metadata field or live external lookup. The casing aliases added for #2982 cover GitHub, 1Password, pfSense and 24 common misses. Names were cross-checked against the [Simple Icons data](https://cdn.jsdelivr.net/npm/simple-icons@latest/data/simple-icons.json) and [selfh.st index](https://cdn.jsdelivr.net/gh/selfhst/icons@main/index.json); qBittorrent uses the selfh.st spelling. These are research sources, not runtime dependencies.

On the 3,424-entry snapshot used for #2982, the initial rule promoted 33 pre-existing aliases over title case, but promotion is not necessarily an improvement. The audit below corrects 11 spellings and restores the title-case fallback for one uncertain identity, while retaining every existing search alias. The final data has 70 matching aliases, 53 of which differ from title case. This is not a claim of full catalogue coverage: eBay, FreeNAS, NextcloudPi, OpenHAB (`openHAB`), Proxmox variants and acronyms such as SABnzbd still need curated matching aliases.
